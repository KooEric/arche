# dbt 모델 테이블과 속성 문서 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dbt 모델과 스냅숏이 만드는 테이블 이름(스키마는 변수)을 lineage에 더하고, `sources.yml`로 `source()`의 실제 테이블 이름을 정하고, 속성 파일의 설명·컬럼·테스트를 `graph.json`과 리포트의 테이블 블록에 문서와 데이터의 비교로 보여 준다. 이 작업으로 Arche는 1.2.0이 된다.

**Architecture:** YAML 리더가 선택 옵션으로 블록 스칼라를 읽고(`yaml_reader`), dbt YAML 추출이 폴더 설정과 속성 문서를 남긴다(`yaml_dbt`). 모델 SQL의 `config()`는 새 `langs/dbt_config.py`가, `source()` 읽기 표시는 `sql_tables`가 맡는다. `dbt.py`가 모델마다 테이블 이름을 조립하고 source 이름을 해석하며, `graph.py`가 이를 `written_tables`·READS·`external_tables`에 반영하고 `dbt_models`·`dbt_sources`·`dbt_docs_unlinked`를 만든다. 리포트는 새 `report_docs.py`가 문서 컬럼과 프로파일 컬럼을 합친 표와 테스트 단서를 그리고, `report_data.py`가 dbt 테이블에도 블록을 연다.

**Tech Stack:** Python 3.9+ 표준 라이브러리(`re`, `posixpath`, `html`, `functools`), pytest.

이 문서는 [dbt 모델 테이블과 속성 문서 설계](../specs/2026-11-26-dbt-docs-design.md)의 구현 계획이다. 브랜치는 `erkoo/dbt-docs`이고 기준은 645acfd(`main` 18cb40d에 설계 문서만 더한 커밋)이다. 이 계획의 모든 코드와 테스트는 임시 폴더의 레포 사본에서 구현해 실행했고, 코드 블록은 그 사본의 파일과 기준 대비 diff를 스크립트로 옮긴 것이다. 각 Task의 실패 메시지와 통과 수는 기준 사본에 Task를 순서대로 다시 적용하며 확인했다. 새 테스트 50개, 기존 테스트, `evals/score.py`, `evals/score_profile.py`, Python 3.9 실행이 모두 통과한다. 그 사본은 git 저장소가 아니어서 `tests/evals/test_experiment.py`(3개)와 `tests/evals/test_release_package.py`(1개)가 실패했는데, 이는 환경 탓이다. 실제 worktree에서는 통과해야 하며, 아래 통과 수는 그 4개를 포함한 worktree 기준이다. 시작 시점의 전체 테스트는 worktree에서 확인한 1043개 통과, 1개 skipped이다.

## Global Constraints

- Python 3.9에서 동작해야 한다. `match` 문, 런타임의 `X | Y` 타입 표기, 3.10 이상 전용 API를 쓰지 않는다.
- 스킬 폴더는 표준 라이브러리만 `import`한다(`tests/test_stdlib_only.py`).
- `block_scalars`의 기본값은 `False`이고, 끄면 `scalars`의 결과가 완전히 같다. 켜는 곳은 dbt 속성 파일을 다시 읽는 `yaml_dbt.extract` 하나뿐이다.
- dbt 프로젝트가 없는 레포에서는 `graph.json`의 기존 키가 바이트까지 같고, `dbt_models`·`dbt_sources`·`dbt_docs_unlinked`는 빈 목록이다. `SCHEMA_VERSION`은 `"1.0"` 그대로이고 새 키와 `written_tables[].via`는 추가 키이다.
- 같은 입력이면 `graph.json`이 바이트 단위로 같다. 목록은 모두 정렬한다(`dbt_models`는 file, `dbt_sources`는 (source, table, resolved, 정의 파일), `dbt_docs_unlinked`는 (path, line, name)).
- YAML·SQL은 신뢰할 수 없는 입력이다. 설명 2,000자, 테스트 이름·값·`data_type` 200자, `accepted_values` 값 10개에서 자르고, `config(`가 10,000자 안에서 닫히지 않으면 그 파일의 config 읽기를 멈춘다. 정규식은 겹치는 반복이 없는 선형 패턴만 쓰고, 중첩을 따라가는 코드는 재귀를 쓰지 않는다. config 호출이 수만 개여도 한 번 훑는다.
- 리포트에 들어가는 설명, 이름, 테스트 인자는 모두 `html.escape`를 거친다. 테스트 단서는 개수와 비율만 보이고 값은 보이지 않는다. 설명 안의 지시문은 데이터로만 다룬다.
- fixture에 사내 코드와 실제 데이터를 넣지 않는다. 모두 합성이다.
- 커밋 메시지는 이 저장소의 관례대로 영어 한 문장으로 쓰고, 귀속(Co-Authored-By) 줄은 붙이지 않는다.
- 모든 명령은 worktree 루트에서 실행한다.

**Interfaces:**
- Consumes: 없음
- Produces: `scalars(text, block_scalars=False, truncated=None)`. `block_scalars=True`이면 `|`·`>` 본문을 키 줄 번호로 낸다. `MAX_BLOCK_CHARS = 2_000`. 잘린 스칼라의 `(key path, line)`을 `truncated` 목록에 더한다. 반환 모양 `(documents, degraded)`는 그대로이다.

본문을 읽는 동안에는 줄을 주석 제거 전 원문으로 다루므로 본문 안의 `#`은 글자이다. 저장하는 본문은 `MAX_BLOCK_CHARS`를 조금 넘으면 멈추므로, 큰 블록도 메모리를 더 쓰지 않는다.

> 스펙 해석: 잘림은 반환 모양을 바꾸지 않도록 선택 인자 `truncated` 목록으로 알린다. `>`의 더 깊이 들여쓴 줄도 다른 줄처럼 접는다(스펙의 규칙 그대로, YAML의 more-indented 예외는 두지 않는다). 공백만 있는 줄은 빈 줄이고, 내용이 없는 블록은 값을 내지 않는다.

```python
"""The `alias` and `schema` a dbt model sets in `{{ config(...) }}`. Not a Jinja parser.

Jinja renders before SQL, so a config call counts even inside a `--` comment;
`{# #}` hides it. Later calls override earlier ones key by key, as in dbt. A
value that is not a single string literal is recorded as dynamic, and a call
inside `{% if %}` or `{% for %}` marks the whole result `branched`.
"""
from __future__ import annotations

import re
from typing import Dict, List, Optional, Tuple

KEYS = ("alias", "schema")
MAX_CALL_CHARS = 10_000
_CALL = re.compile(r"\{\{-?\s*config\s*\(")
_JINJA_COMMENT = re.compile(r"\{#.*?#\}", re.S)
_BLOCK_TAG = re.compile(r"\{%-?\s*(if|for|endif|endfor)\b")
_ARGUMENT = re.compile(r"\s*([A-Za-z_]\w*)\s*=(.*)", re.S)
_LITERAL = re.compile(r"\s*(?:'([^'\\\n]*)'|\"([^\"\\\n]*)\")\s*")


def _blank_comments(text: str) -> str:
    """`{# ... #}` becomes spaces, keeping newlines, so positions and line numbers stay."""
    return _JINJA_COMMENT.sub(lambda match: re.sub(r"[^\n]", " ", match.group()), text)


def _arguments(text: str, start: int) -> Optional[Tuple[str, int]]:
    """(text between the call's parentheses, index after its `)`), or None when it does not close nearby."""
    depth, quote = 1, None
    limit = min(len(text), start + MAX_CALL_CHARS)
    index = start
    while index < limit:
        char = text[index]
        if quote:
            if char == "\\":
                index += 1
            elif char == quote:
                quote = None
        elif char in "'\"":
            quote = char
        elif char in "([{":
            depth += 1
        elif char in ")]}":
            depth -= 1
            if depth == 0:
                return text[start:index], index + 1
        index += 1
    return None


def _top_level(body: str) -> List[str]:
    """Arguments split at commas outside brackets and strings."""
    parts, depth, quote, begin = [], 0, None, 0
    index = 0
    while index < len(body):
        char = body[index]
        if quote:
            if char == "\\":
                index += 1
            elif char == quote:
                quote = None
        elif char in "'\"":
            quote = char
        elif char in "([{":
            depth += 1
        elif char in ")]}":
            depth -= 1
        elif char == "," and depth == 0:
            parts.append(body[begin:index])
            begin = index + 1
        index += 1
    parts.append(body[begin:])
    return parts


def config(text: str) -> Optional[dict]:
    """{"line", "alias", "schema", "dynamic", "branched"} for the model's config calls, or None without one.

    `alias` and `schema` hold the last literal value given; a key whose last value
    was not a literal is listed in `dynamic` instead. `line` is the last call's line."""
    if "config" not in text:
        return None
    clean = _blank_comments(text)
    tags = [(match.start(), match.group(1)) for match in _BLOCK_TAG.finditer(clean)]
    values: Dict[str, Optional[str]] = {}
    dynamic: Dict[str, bool] = {}
    line, branched, position = None, False, 0
    depth, seen = 0, 0  # open if/for blocks before the current call, and tags counted so far
    breaks, counted = 0, 0  # newlines before `counted`, so line numbers take one pass
    while True:
        call = _CALL.search(clean, position)
        if call is None:
            break
        found = _arguments(clean, call.end())
        if found is None:
            break
        body, position = found
        breaks += clean.count("\n", counted, call.start())
        counted = call.start()
        line = breaks + 1
        while seen < len(tags) and tags[seen][0] < call.start():
            depth += 1 if tags[seen][1] in ("if", "for") else -1
            seen += 1
        branched = branched or depth > 0
        for part in _top_level(body):
            argument = _ARGUMENT.fullmatch(part)
            if argument is None or argument.group(1) not in KEYS:
                continue
            literal = _LITERAL.fullmatch(argument.group(2))
            key = argument.group(1)
            if literal is None:
                values[key], dynamic[key] = None, True
            else:
                values[key] = literal.group(1) if literal.group(1) is not None else literal.group(2)
                dynamic[key] = False
    if line is None:
        return None
    return {"line": line, "alias": values.get("alias"), "schema": values.get("schema"),
            "dynamic": sorted(key for key, flag in dynamic.items() if flag), "branched": branched}
```

_SENTENCE_END = re.compile(r"[.!?。](?=\s|$)")


def _code(text) -> str:
    return f"<code>{escape(str(text))}</code>"


def first_sentence(text: Optional[str]) -> str:
    """The first sentence of a description on one line, at most FIRST_SENTENCE_CHARS characters."""
    flat = " ".join((text or "").split())
    end = _SENTENCE_END.search(flat)
    sentence = flat[:end.end()] if end else flat
    return sentence if len(sentence) <= FIRST_SENTENCE_CHARS else sentence[:FIRST_SENTENCE_CHARS - 1] + "…"


def documented_type(data_type: Optional[str]) -> Optional[str]:
    """The profile type a dbt data_type stands for: `varchar(20)` -> string; None when not mapped."""
    if not data_type:
        return None
    return TYPE_GROUPS.get(data_type.strip().lower().split("(", 1)[0].strip())


def summary(model: dict) -> str:
    """The `dbt` badge and the model description's first sentence, for the table block's summary line."""
    sentence = first_sentence(model["description"])
    return '<span class="badge" data-tone="ok">dbt</span>' + (f' <span class="label">{escape(sentence)}</span>' if sentence else "")


def _test_label(test: dict) -> str:
    """A test name with its main arguments, all escaped."""
    label = _code(test["name"])
    if "values_count" in test:
        label += f' ({", ".join(_code(value) for value in test["values"])}{" …" if test["values_count"] > len(test["values"]) else ""})'
    to = test.get("to", {})
    if "ref" in to:
        label += f' → {_code(to["ref"])}'
    elif "source" in to:
        label += f' → {_code(".".join(to["source"]))}'
    if "field" in test:
        label += f'.{_code(test["field"])}'
    return label

def _hints(column: Optional[dict], tests: List[dict], rows_read: int, T: Translate) -> List[str]:
    """Counts the sample shows against `not_null` and `unique`; never a value."""
    if column is None:
        return []
    names = {test["name"] for test in tests}
    found = []
    ratio = column.get("null_ratio", 0.0)
    if "not_null" in names and ratio > 0:
        found.append(T("In the sample: null {ratio}").format(ratio=f"{round(ratio * 100, PERCENT_DIGITS)}%"))
    if ("unique" in names and "distinct" in column and not column.get("distinct_capped") and ratio == 0
            and column["distinct"] < rows_read):
        found.append(T("In the sample: duplicates"))
    return found


def _badge(text: str, tone: str) -> str:
    return f'<span class="badge" data-tone="{tone}">{text}</span>'


def columns(model: dict, dataset: Optional[dict], cells: Cells, flags: Cells, T: Translate) -> str:
    """One table of documented and profiled columns joined by name, with type differences and test hints."""
    data = dataset.get("columns", []) if dataset else []
    by_name: Dict[str, dict] = {}
    for column in data:
        by_name.setdefault(column["name"].lower(), column)
    rows, used, hinted = [], set(), False
    rows_read = (dataset or {}).get("rows_read") or 0
    for documented in model["columns"]:
        column = by_name.get(documented["name"].lower())
        if column is not None:
            used.add(id(column))
        marks = [flags(column)] if column else []
        if dataset is not None and column is None:
            marks.append(_badge(T("Not in data"), "warn"))
        expected = documented_type(documented["data_type"])
        if column and expected and column["type"] in PROFILE_TYPES and column["type"] != expected:
            marks.append(_badge(T("Type differs"), "warn"))
        hints = _hints(column, documented["tests"], rows_read, T)
        hinted = hinted or bool(hints)
        tests = ", ".join(_test_label(test) for test in documented["tests"])
        tests += "".join(f'<br><span class="badge" data-tone="warn">{hint}</span>' for hint in hints)
        rows.append(f'<tr><td>{_code(documented["name"])} {" ".join(mark for mark in marks if mark)}</td>'

                    f'<td>{escape(documented["description"] or "")}</td><td>{tests}</td>'
                    f'{cells(column) if column else "<td></td>" * 4}</tr>')

        if id(column) in used:
            continue

Jsonnet 라이브러리 폴더를 `jsonnet -J`로 지정하는 레포는 같은 폴더를 `--jpath DIR`(레포 기준 상대 경로, 여러 번 가능)로 넘기면 그 import가 확정으로 연결됩니다. 레포 밖 폴더의 CSV·TSV·JSON·JSONL·Parquet은 `arche.py REPO --data DIR`로 프로파일해 SQL이 읽고 쓰는 테이블과 맞출 수 있습니다. 리포트의 **테이블**에서 테이블마다 쓰는 파일, 읽는 파일, 컬럼 타입, null 비율, 키 후보를 보여 주고, 문자열 값은 기본으로 보여 주지 않습니다. dbt 레포에서는 모델이 만드는 테이블(스키마는 변수)과 `schema.yml`의 설명·컬럼·테스트를 읽어, 문서와 데이터의 컬럼 차이와 테스트 단서를 같은 블록에 보여 줍니다.
