# 처음 사용하는 사람의 검증 과제

Arche를 처음 써 보는 개발자가 안내 없이 기능 하나를 설명할 수 있는지 확인하는 과제입니다. 공개 이슈에는 개인 레포의 경로, 코드, 보고서 또는 trace를 첨부하지 않아도 됩니다.

1. [README의 설치 절차](../README.md#codex에서-시작하기)를 따라 Codex에 설치합니다.
2. 익숙하지 않은 로컬 레포를 하나 엽니다. 공개 예제로 시험하려면 이 저장소를 내려받고 [수령 확인 앱](../evals/walkthrough-fixtures/ui) 또는 [태그 집계 CLI](../evals/walkthrough-fixtures/cli) 폴더 자체를 Codex에서 엽니다. 설치 ZIP에는 스킬이 들어 있으며 예제 소스는 저장소에서 받습니다.
3. 새 세션에서 `$arche 레포 분석`을 입력합니다. 대화에서 HTML을 열고 관심 있는 기능 하나를 고릅니다.
4. 그 기능의 입력, 결과, 결과를 결정하는 파일과 줄을 찾아 봅니다. UI에서는 어떤 조건에서 버튼이 달라지는지, CLI에서는 입력이 어느 함수에서 출력으로 바뀌는지 설명해 봅니다.

끝나면 아래 네 줄을 복사해 [피드백 이슈](https://github.com/KooEric/arche/issues/new)를 작성하거나 진행자에게 전달하세요. 막힌 경우에는 도달한 단계까지만 적어도 됩니다.

```text
환경 (OS / Codex 버전 / Arche 버전):
설치 / 한 줄 호출 / HTML 열기 (각각 성공 또는 막힘):
찾은 기능, 입력 → 결과, 근거 파일과 줄:
추가 질문이나 도움을 받은 단계 / 가장 헷갈린 설명:
```

진행자는 참가자가 찾아낸 근거를 소스와 대조하고, 도움 없이 완료했는지와 막힌 단계를 기록합니다. 자동 검사 또는 개발자의 리허설 결과는 외부 참가자 결과와 별도로 집계합니다.
