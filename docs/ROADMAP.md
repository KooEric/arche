# Arche 로드맵

AI와 함께 만든 코드베이스를 인수한 개발자와 FDE가 기능을 찾고, 설명의 근거를 확인하고, 변경과 에이전트 결과를 재현하는 데 초점을 둡니다.

| 단계 | 사용자가 하는 일 | 공개 코드와 남은 검증 |
|---|---|---|
| 전체 지도 | 레포 용도, 진입점, 모듈, 정적 import를 조사합니다. | Python·TS·JS·Dart·Go와 오프라인 HTML이 구현되어 있습니다. 언어별 fixture를 CI에서 채점합니다. |
| 기능 흐름 | 화면·버튼·명령을 기준으로 관련 코드와 조건을 따라갑니다. | 기능 집중 보기, 소스 투어, 인용 위치가 일치하는 HTTP 후보가 구현되어 있습니다. 실제 배포 환경의 라우팅과 런타임 호출은 별도의 검증이 필요합니다. |
| 재사용 | 투어를 다른 스킬이나 문서에 전달합니다. | JSON·Markdown·Mermaid와 소비 예제, 이전 산출물 읽기 규약을 제공합니다. |
| 감사 | 두 Git 리비전의 의존 후보와 추가·해소된 감사 후보를 비교합니다. | 순환·반복 import와 보수적인 Python 후보 규칙을 제공합니다. 작은 합성 fixture를 채점했고, 실제 레포의 감사 정밀도는 아직 측정하지 못했습니다. |
| FDE 평가 | 같은 과제를 여러 구성에서 실행하고 실패한 근거를 다시 봅니다. | `arche-eval`이 합성 이해·수정 과제를 실행하고, 저장된 결과를 오프라인으로 재채점하며 블라인드 검토 표본을 생성합니다. |

정식 1.0에서는 산출물 호환성, 설치부터 보고서 열기까지의 클라이언트별 검증, 독립 사용자의 평가 재현을 확인합니다. 릴리스는 같은 태그에서 스킬 ZIP 두 개와 체크섬을 생성합니다.
