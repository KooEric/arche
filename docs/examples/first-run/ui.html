소스 근거 후보 0

확정된 결함이 아니라 검토 후보입니다. Python에서는 공개 export를 기본적으로 보호하고, 명시적으로 지정한 내부 디렉터리만 선언된 Python export와 대조합니다. 외부 사용자를 배제할 수 없습니다. 테스트, fixture, 생성·vendor 경로, 패키지 진입점, 데코레이터가 붙은 정의, 참조된 이름은 제외합니다. 동적 로딩과 스캔하지 않은 코드에 사용처가 숨어 있을 수 있습니다. 수정 전에 인용된 소스와 호출부를 비교하세요. Java와 Kotlin에서는 이름이 다른 어디에도(문자열과 설정 파일 포함) 나오지 않는 private 멤버와 비공개 최상위 타입이 후보입니다. 어노테이션이 붙은 선언은 제외하며, 리플렉션이나 생성 코드가 쓰고 있을 수 있습니다. TypeScript·JavaScript·Dart·Go에서는 export되지 않았고 이름이 파일·라이브러리·패키지 안에서 한 번만 나오는 선언이 후보입니다.
